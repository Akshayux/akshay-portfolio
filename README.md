# Akshay Venkata Narayana - Product & UX Designer

Portfolio website for Akshay Venkata Narayana, featuring selected product-design work, case studies, professional experience, and recommendations.

## Local development

Requirements:

- Node.js 22.13 or newer
- npm

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in a browser.

## Checks

```bash
npm run lint
npm run build
```

## Main routes

- `/` - Portfolio overview
- `/work` - Selected work
- `/work/luxtj` - LUXTJ customer experience case study
- `/work/luxtj-extranet` - LUXTJ partner operations case study
- `/work/scotcare` - ScotCare case study
- `/about` - About and experience
- `/resume` - Resume
- `/contact` - Contact details

## Technology

- React 19
- Next.js 16
- Vinext and Vite
- Motion
- Cloudflare Workers-compatible Sites deployment
